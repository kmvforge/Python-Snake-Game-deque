# Snake Game 🐍 (Python Pygame)

## 📌 Project Overview
This is a classic Snake Game built using Python and Pygame. The game demonstrates real-time user interaction, collision detection, scoring system, and game loop design.

---

## 🎮 Features
- Smooth real-time snake movement
- Food generation at random positions
- Score tracking system
- Collision detection (wall and self)
- Pause and restart functionality
- Game over screen
- Increasing difficulty with progression

---

## 🧠 Concepts Used
- Data Structures (Queue / Deque logic for snake body)
- Event-driven programming
- Game loop architecture
- Collision detection algorithms
- State management

---

## 🛠️ Technologies Used
- Python
- Pygame
